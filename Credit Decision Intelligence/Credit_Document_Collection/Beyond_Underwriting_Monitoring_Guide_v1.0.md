# Beyond Underwriting Monitoring Guide v1.0

**Effective date:** 01-Sep-2026  
**Document type:** Synthetic Demo Monitoring Guide

## 1. Purpose
Where a recommendation or endorsement depends on a compensating factor, condition, or forward-looking assumption, that assumption should become a monitoring obligation if the facility is sanctioned.

## 2. Examples
- Temporary delinquency cured -> monitor DPD and returns.
- Collateral enhancement promised -> verify required coverage before implementation and thereafter as required.
- Limited operating history exception -> monitor financial performance and conduct while vintage develops.
- High customer concentration -> monitor concentration and evidence of diversification.
- Facility justified by order-book growth -> monitor sales/GST and utilisation against the underwriting thesis.

## 3. Status
The `underwriting_assumption_register.csv` contains **planned-if-sanctioned** obligations. Their presence does not prove a facility has been sanctioned.

## 4. Early-warning principle
If an assumption that materially supported an exception or endorsement stops holding, the case should be surfaced for credit review. The monitoring layer should explain which original assumption changed and which decision relied on it.
